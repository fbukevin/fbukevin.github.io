因為寫了一段 for-loop，覺得有點醜，所以想試試看請 AI 幫我改，雖然已經有安裝 Codeium，但想說 GitHub 的 code base 多，想試試看 GitHub Copilot，個人使用一個月 10 美金也還好，就訂閱下去了。

訂閱好後，我想在 Visual Studio Code 中使用，除了要安裝 GitHub Copilot 的套件，接著還要登入 GitHub 帳號，然後點選 VSCode 左邊的「聊天」選項。

![聊天](https://cdn-images-1.medium.com/max/55/1*NrE6wRVPd1LD8JA4GjKB2w.png)
*聊天*

依據提示，可以直接在檔案中使用內嵌聊天，我先把想請 AI 修改的地方反白，然後就會跳出聊天視窗，沒有跳出來的話，也可以點選旁邊出現的橘色燈泡選擇。

![](https://cdn-images-1.medium.com/max/1024/1*6BukZAu7NDtMNfXzqT8B6w.png)
*輸入希望修改的方式(e.g. 優化)*

執行輸入的 prompt 後，就會開始動作，修正/建議過程中會一步一步變動，感覺很像在看教學。
![](https://cdn-images-1.medium.com/max/1024/1*p2Zk7NOWXSHz0U1rVcrFGw.png)
*原本的邏輯 (左) 建議修改後的新邏輯(右)*

![](https://cdn-images-1.medium.com/max/1024/1*6bhtl53n9BAAfX6bx4qS_A.png)
*套用建議修改的邏輯*

> 個人心得是覺得蠻厲害的，但就如同 Copilot 自己說的，畢竟是 AI，很可能出錯，建議還是要做驗證跑跑看。
